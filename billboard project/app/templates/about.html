System Architecture

This project implements an end-to-end edge analytics pipeline on a standard Windows laptop:

  1. Video Capture: Continuous webcam frame acquisition via OpenCV.
  2. Object Detection: Ultralytics YOLOv8 inference targeting the person class.
  3. Centroid / IoU Tracking: Temporary tracking IDs to prevent duplicate counts across continuous frames.
  4. Monitoring Zone (ROI): Region-of-interest evaluation to distinguish casual passersby from engaged presence.
  5. Session Lifecycle: Session initialization on entry, grace period timeout on departure, and duration calculation.
  6. Advertisement Attribution: Dynamic association with the currently playing billboard advertisement.
  7. Data Persistence: Storage in local SQLite database via SQLAlchemy.
  8. Live Dashboard: Periodic polling and Chart.js visualizations.
