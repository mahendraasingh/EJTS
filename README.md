# EJTS Enterprise & Academic Engineering Projects Repository

A multi-project monorepo housing production-grade applications, systems engineering implementations, and academic database management systems.

---

## 📂 Project Directory

### 1. 🏆 [Online Quiz Platform with Real-Time Leaderboard](./Online%20Quiz%20Platform%20with%20Real-Time%20Leaderboard)
- **Domain**: College DBMS Capstone Architecture (MySQL + Redis + MongoDB)
- **Features**: Live React 18 & Socket.IO quiz engine, countdown timer, auto-submit, Redis Sorted Set ($O(\log N)$) live leaderboard with deterministic tie-breaking, Redis TTL ephemeral sessions, and MongoDB multi-stage aggregation analytics ($match, $group, $unwind).
- **Stack**: React 18, Vite, Tailwind CSS, Node.js, Express.js, Socket.IO, MySQL 8, Redis 7, MongoDB 7, Docker Compose.

### 2. 🛡️ [Vulnerability Risk Prioritization Tool](./vernability%20risk%20prioritization%20tool)
- **Domain**: Enterprise Cybersecurity & Vulnerability Risk Management
- **Features**: Multi-factor contextual risk scoring engine (CVSS, EPSS exploit prediction, business asset criticality, threat intelligence), dark obsidian security UI, CSV bulk import, and remediation tracking.
- **Stack**: FastAPI (Python), SQLAlchemy, SQLite, React, TypeScript, Tailwind CSS, Recharts.

### 3. 🔍 [Smart Search Engine with Autocomplete](./Smart%20Search%20Engine%20with%20Autocomplete)
- **Domain**: High-Performance Systems & Information Retrieval
- **Features**: Custom C++ Trie data structure for prefix-based instant autocomplete, N-gram inverted index, multi-factor BM25-inspired ranking, zero-dependency WinSock2 HTTP server, and interactive web interface.
- **Stack**: C++17, WinSock2, CMake, HTML5, CSS3, JavaScript.

### 4. 📺 [Smart Billboard AI Analytics](./billboard%20project)
- **Domain**: Edge Computer Vision & Campaign Attribution
- **Features**: Real-time webcam perception pipeline using Ultralytics YOLOv8 person detection, centroid multi-frame tracking, ROI audience engagement zone isolation, 3D WebGL Three.js billboard digital twin, and deep analytics.
- **Stack**: Python, Flask, OpenCV, YOLOv8, SQLite, Three.js, Chart.js.
