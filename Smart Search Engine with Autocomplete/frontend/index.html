Under the Hood

How This Search Engine Works

1
Trie Prefix Autocomplete: As you type, the Trie traverses down prefix branches in O(L) time and uses a frequency-weighted DFS to extract the top suggestions.
2
Inverted Indexing: An unordered_map<string, vector<int>> maps tokenized words directly to document IDs for instant O(1) candidate lookup.
3
Multi-Factor Ranking: Documents are scored by title matches, keyword relevance, description frequency, and base popularity.
4
Priority Queue Top-K: A Min-Heap (priority_queue) retains the top 10 highest-scoring documents in O(N log K) time.
