# Online Quiz Platform with Real-Time Leaderboard

A comprehensive online quiz platform with real-time leaderboard capabilities, live score tracking, and competitive multiplayer quizzing.

## 🌟 Key Features
- **Dynamic Quiz Engine**: Timed questions, category filtering, and instant feedback.
- **Live Leaderboard**: Real-time score updates and live rank recalculations.
- **Player Analytics**: User performance history, accuracy metrics, and speed tracking.
